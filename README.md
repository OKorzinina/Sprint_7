# Финальный проект 7 спринта #

### Тестирование API учебного сервиса Яндекс Самокат - https://qa-scooter.praktikum-services.ru/ ###

**Файлы проекта:**

* allure_results - директория с отчетами о тестировании
* tests/ - каталог с тестами
* endpoints.py - файл с эндпоинтами
* urls - файл с URL сервиса
* helps.py - вспомогательные данные для тестирования
* requirements.txt - файл с внешними зависимостями
* conftest.py - файл с фикстурой
